# LAST DROP — 배틀로얄 웹 에디션 (1단계 + 2단계 대부분 + v2 그래픽/조작 + v3 총기 확장·보급상자 + v4 랭크전·8km 맵 + v5 차량 + v6 로비 개편)

Three.js r128 기반, 서버 없이 브라우저에서 실행되는 싱글플레이 배틀로얄. 모든 상대는 AI 봇.

## 실행
- `dist/index.html` 을 브라우저로 열면 바로 실행됩니다 (three.js는 cdnjs에서 로드).
- 소스 수정 후 `node build.js` → `dist/last-drop.html`(아티팩트용), `dist/index.html`(단독 실행용) 재생성.

## v4 업데이트 (랭크전 · 8km 맵)
### 랭크전
- 레벨 3부터 해금. 로비 상단 `일반전 / 랭크전` 선택, 랭크 카드 → `티어표`에서 전체 티어·규칙 확인
- 티어 10개 × 단계 4→3→2→1: 아이언 · 브론즈 · 실버 · 골드 · 플래티넘 · 다이아 · **마스터 · 그랜드마스터 · 레전드 · 이터널**(추가 4개, 이름은 자체 작명). 단계당 100 RP, 티어당 400 RP, 이터널 1(3900 RP+)은 상한 없음
- 배치고사 3판: 판마다 `순위 곡선 50 + 우승 30 + 처치×8(최대 10) + 피해/50(최대 1500)` → 합계×3.5 = 시작 RP (최대 1999 = 플래티넘 1)
- 배치 후 1판: `50×(1−순위비율)² − 18 + 우승 23 + 처치×6 + 피해/100 − 티어×2.5`, −45~+140으로 제한. 중도 이탈은 최소 −35
- 랭크전은 봇 수·난이도 고정(일반 맵 40명, 노르덴 99명). 난이도 비율은 티어가 오를수록 어려움 비중 증가(아이언 0% → 이터널 80%)
- 엠블럼: 이미지 파일 없이 캔버스로 그림. 상위 티어일수록 날개·월계수·왕관·보석·후광·불꽃·프리즘 테두리가 추가됨
### 노르덴 (8×8km, 봇 최대 99명)
- 도시 3 · 군사기지 2 · 마을 18 등 POI 35곳, 건물 약 700채, 산맥 4, 큰 호수 3, 강
- 맵을 고르면 로비에 렉·메모리 경고 표시. 수송기 경로 10.4km, 활공 거리 약 2.2배(낙하산을 일찍 펴면 1km 이상)
- 자기장 8단계(첫 원 반경 2300m). 쾌속전이어도 첫 대기는 최소 230초(비행·강하만 1~2분)
- 성능 구조: 지형 500m 청크 스트리밍, 식생 청크 컬링, 바닥 아이템 메쉬 지연 생성, 600m 밖 봇은 2프레임에 1번 갱신, 내비 타일 지연 생성
- 봇 착지: 비행 경로에서 활공 가능한 거리(1.1km) 안, 첫 안전구역 쪽 우선, 80m 안 2명 초과 금지 → 착지 오차 3m 이내
### 봇 AI 수정 (모든 맵)
- 주택 칸막이 벽이 현관문 한가운데로 이어져 **집의 약 15%에 봇이 못 들어가던 문제** 수정 (문 앞→실내 경로 성공 84–86%→98%, 1층 아이템 도달 83–87%→98–99%)
- 2층 주택은 1층을 본 뒤 계단으로 올라가 위층도 파밍, 위층 적 추격 가능 (전에는 무기 약 30%가 있는 위층에 봇이 못 감)
- 맨손 봇이 판단할 때마다 30% 확률로 총소리 쪽으로 달려가던 문제 수정, 아이템 앞에서 경로 재탐색만 반복하던 문제 수정
- 무기 출현 비율 약 45% 상향(탄약 단독 비중은 낮춤 — 무기마다 탄 2묶음 동반)

## v9 업데이트 (듀오·스쿼드 3단계: 동승·차량 사격 + 핑 정리)
- 좌석: 말 1 · 오토바이 2(뒷자리) · 세단/UAZ 4 · 픽업 4(뒤 2자리는 적재함). `F` 탑승(운전석이 비면 운전석, 아니면 빈 동승석), `C`/`좌석` 버튼으로 다음 빈 좌석(운전석 ↔ 동승석)
- 동승석: 마우스(터치) 자유 시점 + 조준·사격·장전·무기 교체·사격 모드·회복. 조준하지 않으면 차량 추적 카메라에서 허리 사격, 조준하면 조준경 시점. 달리는 차에서는 속도에 따라 탄 퍼짐 증가(최대 2.6배). 운전자는 사격 불가
  - 같은 차에 탄 사람은 서로의 사선·카메라 조준선에서 제외(뒷자리 팀원 몸에 막히지 않음), 내가 탄 차의 차체도 내 사격·시야를 가리지 않음
  - 충돌·추락 피해, 차량 폭발(전원 탈락급 피해), 말이 쓰러질 때 하차는 탑승자 전원에게 적용
- 봇: 플레이어가 차에 타면 플레이어 팀원이 60m 안이면 달려와 동승석에 탐(운전석은 플레이어 몫), 플레이어가 내리면 같이 내림. 동승한 봇은 보이는 적을 차 안에서 쏨(반응 시간 동일). 봇 팀은 팀장만 운전하고 팀원 수에 맞는 차를 고르며, 팀원이 타러 오는 동안 최대 12초 기다렸다가 출발, 운전자가 내리면 동승자도 내림

## v10 — 동작·소리 다듬기 (스킨 작업 전)
- **줍기 동작·소리**: 줍는 순간 허리를 굽혀 오른손을 바닥으로 뻗는 동작(0.5초, 플레이어·봇 공통). 소리는 물건 종류별로 다르게 합성 — 탄약(탄 상자 달그락), 산탄(플라스틱 탄피), 총(천 스침 + 무거운 철컥 + 멜빵 고리), 권총, 붕대(포장 바스락), 구급상자(지퍼), 의료 키트(케이스 걸쇠), 음료(캔 딸깍), 조끼(쿵 + 벨크로), 헬멧(속이 빈 껍데기 울림), 가방(지퍼), 부착물(딸깍), 투척물(금속 핀). 22m 안의 봇이 줍는 소리도 위치에서 들린다
- **넘기·오르기**: 점프(Space/점프 버튼) 때 정면 0.3~0.95m에 장애물이 있으면 높이·두께·위 공간을 검사 — 높이 0.6~1.4m·두께 1.35m 이하면 넘기(창문·담·모래주머니·난간, 약 0.65초), 1.4~2.05m이고 윗면이 0.45m 이상 평평하면 오르기(상자·폐차, 약 1초). 몸통 폭(±0.2m)으로 검사해 창문 가장자리·좁은 틈은 거부, 착지 지점에 몸이 들어갈 공간이 없으면 거부. 모바일 점프 버튼이 '넘기'/'오르기'로 바뀜. 넘는 동안 다리를 접고 손을 짚는 동작
- **낙하**: 0.2초 넘게 떨어지면 팔을 벌리고 다리를 굽힌 공중 자세. 착지 속도에 따라 가볍게 굽힘 → 크게 웅크림 → 약 3.3m 이상(11.5m/s)이면서 움직이던 중이면 앞구르기. 낙하 피해 완화: 4.5m부터, 6.4m(2층 지붕) 약 11 · 10m 약 29 · 20m 약 65 (예전: 3.6m부터, 6.4m 28)
- **총소리 재설계**: 기존 소리는 0.1~0.25초 만에 끊기고(잔향 꼬리 없음) 에너지의 42~80%가 100Hz 미만(휴대폰 스피커가 재생 못 하는 대역)이라 폰에서는 '딸깍'만 남았다. 새 합성: 크랙(깨끗하게) + 150~350Hz 저중역 폭압(휴대폰에서도 '쿵'이 들리는 대역) + 피치가 급강하하는 킥 + 중역 스냅 + 가스음 + 지형 메아리 + 0.6~2초 굴러가는 저역 꼬리, tanh 포화와 렌더 후 소프트 리미터로 밀도↑. 측정(M416): 첫 150ms 음압 -12.4 → -8.7dBFS, 꼬리(-40dB) 0.15 → 0.75초, 300Hz~1kHz 비중 6% → 15%. 마스터 압축(-12dB·2ms → -9dB·6ms)이 총성 몸통을 깎던 문제 수정 + 최종 리미터 추가. 내 총 볼륨 약 +1.5dB
- **회복 동작**: 붕대(왼팔에 감기), 구급상자·의료 키트(왼손에 들고 처치), 에너지 드링크(캔을 입으로) — 회복 중엔 총을 내리고 아이템을 손에 듦. 1인칭은 손과 아이템이 화면에 보임. 아이템별 시작·완료 소리(봇은 18m 안에서 들림)
- **모바일 회복·투척 선택**: 버튼을 누르면 바로 위에 가진 아이템이 아이콘·개수·효과와 함께 가로로 펼쳐짐(위 공간이 없으면 옆). 회복 중 회복 버튼 = 취소, 투척 준비 중 투척 버튼 = 취소
- **투척 개편**: 투척 준비 → 손에서 착지 지점까지 궤적 점선 + 착지 표시(실제 투척물과 같은 물리, 튕김 제외) → 사격 버튼을 누르면 핀 뽑기(카운트다운 시작) → 떼면 투척. 수류탄 7초·연막탄 3초(핀 기준). 쥐고 있다 시간이 다 되면 손에서 폭발(치명상). 남은 시간은 조준점 오른쪽 원형 카운트다운으로, 던진 뒤에도 폭발까지 표시. 투척물은 1/60초 단위로 계산해 프레임률과 무관하게 예측과 일치. 바닥에 튕기는 소리 추가. 봇은 숙련도별로 쿠킹한 것으로 처리(남은 시간: 쉬움 4.8~5.8 / 보통 3.4~4.6 / 어려움 2.6~3.6초)
- **소리 방향 표시**: 조준점 둘레에 주황 호 — 발소리(최대 30m, 얇은 호 + 발자국 점), 총소리·폭발(230~260m, 굵은 호 + 바깥 눈금), 가까운 적 수류탄(11m, 빨간 깜빡임). 거리·시간에 따라 옅어짐. 나·팀원 소리는 제외
- 벽·창문 앞에서 3인칭 카메라가 너무 가까워지면 내 캐릭터를 숨겨 머리가 화면을 가리지 않게

## v12 — 로그인 (Supabase)
- 로비 오른쪽 위 '로그인' → 아이디(= 게임 속 이름, 2~10자 한글·영문·숫자·_) + 비밀번호(6자 이상)로 가입·로그인. 대소문자만 다른 아이디는 같은 아이디
- 서버에 저장: 전적·레벨/경험치·랭크·설정(조작·소리·외형 등). 기기마다 다른 화면 품질·그림자·터치 버튼 배치·감도는 저장하지 않음
- 저장 시점: 기록·설정이 바뀌고 2초 뒤 자동 + 화면을 벗어날 때(앱 전환) + '지금 저장'
- 처음 가입하면 이 기기의 게스트 기록이 계정으로 옮겨짐. 이미 기록이 있는 계정으로 로그인하면 서버 기록을 불러옴. 로그아웃하면 이 기기의 게스트 기록으로 돌아감
- 서버 설정이 비어 있거나(`src/00_config.js`의 url·key) 서버에 닿지 않으면 로그인 버튼이 숨거나 오류만 표시되고, 게임은 게스트로 그대로 동작
- 구조: 아이디를 내부용 이메일 `u<아이디 UTF-8 16진수>@lds-training.vercel.app`으로 바꿔 Supabase Auth(이메일+비밀번호)에 가입. 실제 메일은 보내지 않음 → 대시보드에서 **Confirm email을 꺼야** 함
- 서버 준비: `supabase/schema.sql`을 SQL Editor에서 한 번 실행(테이블 `profiles`·`player_data`, 본인 행만 읽기/쓰기 RLS, 가입 시 행 자동 생성)
- 키: 클라이언트에는 Publishable(anon) 키만 넣는다. service_role(secret) 키는 절대 넣지 않는다
