# LAST DROP — 배틀로얄 웹 에디션 (1단계 + 2단계 대부분 + v2 그래픽/조작 + v3 총기 확장·보급상자 + v4 랭크전·8km 맵 + v5 차량 + v6 로비 개편)

Three.js r128 기반, 서버 없이 브라우저에서 실행되는 싱글플레이 배틀로얄. 모든 상대는 AI 봇.

## 실행
- `dist/index.html` 을 브라우저로 열면 바로 실행됩니다 (three.js는 cdnjs에서 로드).
- 소스 수정 후 `node build.js` → `dist/last-drop.html`(아티팩트용), `dist/index.html`(단독 실행용) 재생성.

## v2 업데이트 내용
- **장전 모션**: 무기별 상태머신 — 탄창식(AR-7·SK-74·VK9·DM-14·P-19: 잔탄 장전/빈 탄창 장전 분리, 빈 탄창 시 장전손잡이·슬라이드 조작), S-12 한 발씩 장전(사격 시 중단 가능)+펌프, BR-98 볼트 개방→한 발씩→폐쇄+사격 후 볼트 조작. 1인칭 뷰모델과 3인칭 캐릭터 모두 부품이 실제로 움직임. 탄피 배출 물리.
- **총성**: 무기별 파라미터(폭발음 대역·잔향 길이·기계음)로 사전 렌더, 자기 총/원거리 총성 분리, 실내 잔향, 거리 지연.
- **조준경**: 레드닷, 홀로그램, 2·3·4·6배율. 각각 감도 설정(설정 → 감도). 배율 조준경은 스코프 화면(렌즈 비네팅·레티클), 3·4·6배율은 호흡 흔들림(PC는 Shift로 숨 참기). 장착 제한: 권총은 레드닷/홀로만, 산탄총 ≤2배, 기관단총 ≤4배.
- **아이템 사진**: 가방·바닥 목록·무기 슬롯·부착물 슬롯·HUD에 3D 모델 렌더 아이콘 35종.
- **바닥 아이템**: 탄약 상자, 회복약, 총(부착물 포함 외형) 등을 실제 모델로 표시.
- **모바일**: 이동 중 사격(사격 중 자동 달리기 해제), 설정 → 버튼 배치 편집(드래그 이동, 버튼별 크기 50–200% + 전체 크기 70–150%, 겹침 경고, 저장/초기화), 고정 조이스틱 옵션.

## v10 — 동작·소리 다듬기 (스킨 작업 전)
- **줍기 동작·소리**: 줍는 순간 허리를 굽혀 오른손을 바닥으로 뻗는 동작(0.5초, 플레이어·봇 공통). 소리는 물건 종류별로 다르게 합성 — 탄약(탄 상자 달그락), 산탄(플라스틱 탄피), 총(천 스침 + 무거운 철컥 + 멜빵 고리), 권총, 붕대(포장 바스락), 구급상자(지퍼), 의료 키트(케이스 걸쇠), 음료(캔 딸깍), 조끼(쿵 + 벨크로), 헬멧(속이 빈 껍데기 울림), 가방(지퍼), 부착물(딸깍), 투척물(금속 핀). 22m 안의 봇이 줍는 소리도 위치에서 들린다
- **넘기·오르기**: 점프(Space/점프 버튼) 때 정면 0.3~0.95m에 장애물이 있으면 높이·두께·위 공간을 검사 — 높이 0.6~1.4m·두께 1.35m 이하면 넘기(창문·담·모래주머니·난간, 약 0.65초), 1.4~2.05m이고 윗면이 0.45m 이상 평평하면 오르기(상자·폐차, 약 1초). 몸통 폭(±0.2m)으로 검사해 창문 가장자리·좁은 틈은 거부, 착지 지점에 몸이 들어갈 공간이 없으면 거부. 모바일 점프 버튼이 '넘기'/'오르기'로 바뀜. 넘는 동안 다리를 접고 손을 짚는 동작
- **낙하**: 0.2초 넘게 떨어지면 팔을 벌리고 다리를 굽힌 공중 자세. 착지 속도에 따라 가볍게 굽힘 → 크게 웅크림 → 약 3.3m 이상(11.5m/s)이면서 움직이던 중이면 앞구르기. 낙하 피해 완화: 4.5m부터, 6.4m(2층 지붕) 약 11 · 10m 약 29 · 20m 약 65 (예전: 3.6m부터, 6.4m 28)
- **총소리 재설계**: 기존 소리는 0.1~0.25초 만에 끊기고(잔향 꼬리 없음) 에너지의 42~80%가 100Hz 미만(휴대폰 스피커가 재생 못 하는 대역)이라 폰에서는 '딸깍'만 남았다. 새 합성: 크랙(깨끗하게) + 150~350Hz 저중역 폭압(휴대폰에서도 '쿵'이 들리는 대역) + 피치가 급강하하는 킥 + 중역 스냅 + 가스음 + 지형 메아리 + 0.6~2초 굴러가는 저역 꼬리, tanh 포화와 렌더 후 소프트 리미터로 밀도↑. 측정(M416): 첫 150ms 음압 -12.4 → -8.7dBFS, 꼬리(-40dB) 0.15 → 0.75초, 300Hz~1kHz 비중 6% → 15%. 마스터 압축(-12dB·2ms → -9dB·6ms)이 총성 몸통을 깎던 문제 수정 + 최종 리미터 추가. 내 총 볼륨 약 +1.5dB
- **회복 동작**: 붕대(왼팔에 감기), 구급상자·의료 키트(왼손에 들고 처치), 에너지 드링크(캔을 입으로) — 회복 중엔 총을 내리고 아이템을 손에 듦. 1인칭은 손과 아이템이 화면에 보임. 아이템별 시작·완료 소리(봇은 18m 안에서 들림)
- **모바일 회복·투척 선택**: 버튼을 누르면 바로 위에 가진 아이템이 아이콘·개수·효과와 함께 가로로 펼쳐짐(위 공간이 없으면 옆). 회복 중 회복 버튼 = 취소, 투척 준비 중 투척 버튼 = 취소

- 상점 컷신·로비 받침대·로비 캐릭터에서도 같은 빛 띠

- **모든 스킨**: 로그인할 때마다 옷(45)·차량(10)·총기(28) 스킨을 전부 계정 기록에 넣음 → 서버에 저장되고, 새 스킨이 생기면 다음 로그인 때 추가. 창고에서 바로 장착
- **표시**: 로비 오른쪽 위 하늘색 렌치 버튼(DEV) · 계정 칩 테두리 하늘색. 로그아웃하면 게스트 기록으로 돌아가 스킨·버튼 모두 사라짐
- **개발자 도구** (로비 렌치 버튼 · 경기 중 메뉴 → 개발자 도구)
  - 재화: 골드 탄피 +10,000 · 차량 코인 +100 · 총기 코인 +100
  - 레벨·미션: 레벨 +1 / +5 · 출석 다시 받기 · 일일·주간 미션 모두 완료 · 스킨 다시 지급
  - 경기(켜고 끄기): 무적 · 무한 탄약(탄창이 줄지 않음) · 지도 눌러 순간이동(전체 지도에서 짧게 누른 곳으로) · 자기장 멈춤(줄지도 피해를 주지도 않음)
  - 경기(즉시): 총 지급(24종 중 선택, 맞는 조준경·보정기·대용량 탄창·손잡이 + 탄약 5탄창) · 장비 풀세트(3레벨 헬멧·조끼·가방, 회복·수류탄, 체력·부스트 가득) · 차량 소환(앞 5m) · 자기장 다음 단계 · 적 모두 탈락(처치자 없이 → 배틀로얄이면 바로 우승)
  - 표시: FPS·프레임 시간·좌표·생존 인원·메모리(지오메트리/텍스처) 상단 표시
  - 켜고 끄는 값은 이 기기에만 저장. **같이 하기(파티) 경기에서는 경기 치트가 꺼짐**(다른 사람 경기에 영향 없게). 훈련장에서는 '적 모두 탈락' 대신 더미를 쏴서
- **한계**: 재화·판정이 모두 기기에서 돌아가는 구조라 서버가 막아 주는 권한이 아니다. 아이디는 먼저 가입한 사람이 가지므로 '개발자'는 직접 먼저 가입해 둘 것

## v20 — 새 맵 키나루(4km 정글) · 노르덴 개편 · 1:1 / 2:2 대결 · 파티원 스킨 표시
### 키나루 (4×4km 열대 정글 섬, 봇 최대 64명)
- 실제 게임의 지명·배치·건물은 쓰지 않고 장르적 특징(열대 섬·정글·강·사원 유적·계단논)만 참고한 자체 맵
- 두 갈래 강: 본류가 섬을 가로지르고, 지류는 본류 한쪽에서만 흐르다 합류 → 땅이 셋으로 나뉘어 다리 싸움이 생김
- 지역 24곳: 정글 훈련소 · 읍내 2 · 사원 유적(4단 기단, 단마다 2.4m · 앞뒤 돌계단 · 꼭대기 사당 · 기둥 길) · 해변 리조트 · 수상 마을(판자 길 + 기둥 위 집) · 부두(콘크리트 부두 · 크레인 · 컨테이너) · 정글 기지 3 · 채석장 · 계단논 3(평탄화 대신 1.9m 단, 단마다 논물/벼 색) · 작은 마을 12
- 식생: 키 큰 활엽수(13m 줄기 + 넓은 수관 2단) · 중층 나무 · 야자수(해변·강가) · 대나무 덤불 · 고사리 — 노르덴보다 훨씬 빽빽. 안개를 가깝고 푸르게
- 흙길(정글 도로)은 차량 접지가 포장도로와 같고, 먼지가 남
- 자기장 8단계를 8km 맵보다 짧게(첫 구역 1.95km, 한 판 약 22분), 수송기 5.4km, 활강 배율 1.5, 차량 64대
### 노르덴 개편 (8×8km)
- 문제: 숲길만 길게 이어져 걷기만 하는 게임이 됨 → 탁 트인 들판·길가 마을·주유소로 이동 중 들를 곳을 만듦
- 지형: 능선을 꺾은선으로 정의한 산맥 3줄(1.7~2.7km · 폭 0.9~1.2km · 130~185m), 바위는 능선 꼭대기만, 구릉/들판, 저주파 잡음 해안선(만·곶)
- 들판: 46×30m 필지마다 작물 색, 필지 경계 일부에 나무 울타리(엄폐물)
- 도로: 거친 격자 A*(경사·강 건너기 비용, 기존 도로 재사용 할인) → 직선화 → Chaikin 곡선, 꺾이는 곳은 마이터로 이어 그림. 강을 건너는 구간은 직선으로 펴고 도로 방향으로 돌린 다리 상판
- 길가 작은 마을 46곳(길에서 25~55m 안쪽 집 3~5채) + 주유소 8곳(지붕·주유기·매점·간판). 지도 이름은 확대했을 때만 표시
- 특수 지역 9곳: 학교 · 교도소(5.5m 담·감시탑 4) · 발전소(냉각탑·굴뚝·터빈 건물·변전 설비) · 채석장(계단식 구덩이·컨베이어·호퍼) · 성터(무너진 성벽·모서리 탑·성벽 위 계단·본성) · 레이더 기지(산 위, 레이돔·안테나) · 병원(3층·헬기장) · 저택(담장 정원·분수·수영장) · 등대
- 특수 지역은 도로가 가장자리 입구에서 끝나고(정문이 그쪽), 다른 지역으로 가는 도로가 가로지르지 않음
- 큰 건물(1~3층): 앞쪽 복도 + 뒤쪽 방들 + 끝 계단(얇은 디딤판)
