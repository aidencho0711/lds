- 상태: 준비(가드) → 지르기 → 복귀. 누르고 있으면 좌우 번갈아 연타
- `04_motion.js` 의 2뼈 IK 로 3인칭 자세 — 가드는 **주먹을 턱 높이**, 팔꿈치는 아래로 (벌어지면 어색함)

검증: 봇을 때려 피해가 들어가는지, 3인칭·1인칭 자세 캡처.

## 2. 슈퍼레어 총기 스킨의 약한 효과

지금은 울트라레어(빨강)에만 피격·처치 효과가 있습니다. 슈퍼레어에도 **절제된** 효과를 넣습니다.

- 울트라레어 효과(`05_models_gskinfx.js`)를 재사용하되 입자 수·밝기·지속을 크게 줄인 "lite" 변형
- 몸체 전체가 빛나는 연출이나 처치 마크(badge)는 넣지 않음 — 등급 차이가 보여야 함
- 효과는 스킨별 색을 따라가게

검증: 스킨별로 발사·피격·처치 프레임 캡처해 울트라레어와 나란히 비교.

## 3. 울트라레어 스킨 — 부속품 전개 + 저격총·샷건 추가

사용자 요청: *색만 바뀌는 게 아니라 외형이 바뀌어야 하고, 총을 꺼내 들 때 부속품이 같이 나와야 한다.*

- 새 모듈(예: `05_models_gparts.js`)에 스킨별 부속품 세트 정의 (마그마/홍룡/플라즈마/글리치/서리/공허 등)
- 꺼내기 모션의 진행도(sweep)에 맞춰 부속품이 **총 앞쪽부터 차례로 전개**되도록 동기화
- 부속품 위치는 총마다 다르므로, 총 모델에 레이캐스트로 윤곽을 재서 올릴 것
  (고정 좌표로 하면 총기별로 공중에 뜸 — 실제로 겪은 문제)
- 발광 부품을 위해 스킨 셰이더에 **역할(kd) 7 = energy** 추가, 색은 uniform 으로
- 저격소총·샷건용 울트라레어 스킨 신규 2종

검증: 꺼내기 프레임별 캡처로 부속품이 총에 붙어 나오는지, 총기별 위치가 맞는지.

## 4. 차량 스킨을 실제 슈퍼카·하이퍼카처럼

사용자가 AI 로 만든 참고 이미지 3장 제공 (하이퍼카 / 스포츠카 / 럭셔리카). **브랜드 로고·엠블럼·차명 글자는 넣지 않습니다.**

- `05_models_vskin.js` 의 차체를 단면 로프트 방식으로 재작성:
  초타원 단면 + 단조 3차 곡선으로 길이 방향 보간, 바퀴 아치는 안쪽으로 밀어 넣기
- 유리는 별도 분류기로 기둥(A/B/C 필러)을 세우고 반투명 재질 — 통유리로 하면 거품처럼 보임
- 계단처럼 각진 모서리는 쿼드를 한 번 더 분할해서 완화
- 휠 스포크는 **축 기준으로 회전**시켜 배치할 것 (박스를 제 중심에서 돌리면 한쪽에 뭉침)
- 리어윙 엔드플레이트·스플리터·사이드스커트·미러, 테일라이트 발광
- 유리는 너무 어둡게 만들지 말 것 (안이 안 보이면 pay-to-win 이 됨)

주의: 스킨 적용 차량이 18k~26k 삼각형까지 올라갑니다. 모바일에서 확인 필요.

## 5. 엑스트라 품질 + 울트라 FPS

- `00_core.js` 의 `QUALITY` 에 '높음' 위 단계 추가 (LOD 거리·그림자 해상도 4096·캐릭터 그림자)
- FPS 설정: 30/60/120/무제한 + FPS 표시 토글. 프레임 제한은 **일정 기반**(다음 프레임 목표 시각)으로,
  허용 오차는 간격의 20% 정도
- 설정 화면에 주의 문구: 엑스트라 품질과 120fps 는 서로 상충하고, 120Hz 는 브라우저가 허용해야 함

## 6. 리콜 시스템

배틀그라운드의 복귀 시스템과 같은 개념. 팀 모드 전용.

- 팀원이 죽으면 **리콜 카드**를 떨어뜨림 → 주워서 맵의 **리콜 타워**에서 일정 시간 등록 → 비행기로 복귀
- 타워는 월드 생성 때 배치 (큰 맵 10개 / 중간 맵 6개 / 작은 맵 3개 정도, 서로 충분히 떨어뜨려서)

## 8. 새 맵 추가 + 노르덴 개편  ← 가장 큰 작업

### 8-1. 노르덴(8km) 개편

문제: 대부분이 숲길이라 마을까지 한참 걷기만 하고, 산 같은 지형이 없음.

- **지형**: 능선을 꺾은선으로 정의한 **산맥 3줄**(길이 1.7~2.7km, 폭 0.9~1.2km, 높이 130~185m) +
  구릉 지대(능선 잡음) + 들판. 바위 표면은 **산꼭대기 능선에만**, 비탈은 숲·풀
- **해안선**: 저주파 잡음으로 만·곶이 생기게 (둥근 사각형 → 자연스러운 섬 윤곽)
- **도로**: 거친 격자 위 A*(경사 비용, 강 건너기 비용, 기존 도로 재사용 할인) → 직선화 → Chaikin 곡선화.
  꺾은선 도로는 꼭짓점에서 마이터 처리해야 이음매가 안 벌어짐
- **길가 작은 마을(hamlet) 46곳 + 주유소 8곳**: 길에서 25~55m 안쪽에 집 3~5채.
  큰 지역까지 가는 길에 들를 곳이 생겨 "계속 걷기만" 하는 문제를 없앰
- **특수 지역**: 학교·교도소·발전소(냉각탑·굴뚝·변전설비)·채석장(계단식 구덩이·컨베이어)·성터(무너진 성벽·탑)·
  레이더 기지·병원·저택·등대
- **밭**: 가는 줄무늬 대신 46×30m 필지 단위로 작물 색을 정할 것
  (4m 격자에서 줄무늬는 계단처럼 깨져 보임)
- 지역이 한쪽에 몰리지 않도록, 후보 여러 개 중 기존 지역에서 가장 먼 곳을 고르는 방식

### 8-2. 새 맵 — 사녹 기반 정글 맵 (4×4km)

사용자 요청: *배그의 사녹을 기반으로.* 실제 사녹의 배치·지명·건물은 쓰지 않고 **장르적 특징만** 가져옵니다.

- 4×4km 열대 섬, 봇 최대 64, 한 판이 8km 맵보다 짧게 (자기장 단계 조정)
- 두 갈래 강 (본류 + 본류 한쪽에서만 흐르다 합쳐지는 지류) → 땅이 셋으로 나뉘고 다리 싸움이 생김
- 지역: 정글 훈련소, 읍내 2, 사원 유적, 해변 리조트, 수상 마을, 부두, 정글 기지 3, 채석장, 계단논 3, 작은 마을 12
- 식생: 열대 활엽수(키 큰 줄기 + 넓은 수관) / 중층 나무 / 야자수 / 대나무 / 고사리 — 노르덴보다 훨씬 빽빽하게
- 계단논은 지형을 평탄화하지 말고 **1.9m 단으로 끊고** 단마다 색을 번갈아
- 습한 느낌을 위해 안개를 조금 가깝고 푸르게

### 8-3. 맵 추가 시 같이 손봐야 하는 곳

- `00_core.js` `MAPS` 에 항목 추가 (`half`, `maxBots`, `plane`, `zone` 단계 등)
- 로비 지도 그림 (`00_art.js`) — 게임이 만든 미니맵을 360×360 JPEG 로 굽는 게 가장 간단
- `10_hud.js` 맵 크기·경고 문구·지도 확대 배율을 맵 크기에서 계산하도록 (8km 하드코딩 금지)
- `08_vehicle.js` 차량 수, `10_rank.js` 봇 수, `11_game.js` 강하 활강 거리 — 전부 맵 크기 비례로
- 지도 라벨: 작은 마을·주유소는 **확대했을 때만** 표시 (안 그러면 글자가 겹쳐 안 보임)

### 검증 방법

맵 작업은 눈으로 봐야 합니다. 쓰던 방식:

1. 헤드리스로 맵을 생성해 통계(지역 수·종류별 개수·도로 길이·삼각형 수·생성 시간·메모리)를 찍고
2. `W.minimap` 을 PNG 로 저장해 전체 배치를 확인하고
3. 지역마다 플레이어를 근처로 옮겨 지형을 로드한 뒤, 일시정지하고 카메라만 띄워 **내려다보는 스크린샷**을 찍어 확인

작은 맵(kalden·ironridge)의 생성 결과가 **바뀌지 않았는지** 체크섬으로 확인하세요
(높이맵·충돌 박스·전리품·나무 위치를 해시). 공용 코드를 고치면 쉽게 깨집니다.
